# 📚Limkokwing Library API

A production-ready Library Management System built with **FastAPI**, designed to handle book management, user authentication, and borrowing operations with role-based access control.



## Features

-  User Authentication (JWT आधारित)
-  Role System (Admin & Student)
-  Book Management (Add, View)
-  Borrow Books
-  Return Books with Fine Calculation
-  Admin-only Operations
-  FastAPI + SQLAlchemy backend
-  Deployable on Render



##  Tech Stack

- **Backend:** FastAPI  
- **Database:** SQLite (can be upgraded to PostgreSQL)  
- **ORM:** SQLAlchemy  
- **Authentication:** JWT (python-jose)  
- **Password Hashing:** Passlib (bcrypt)
